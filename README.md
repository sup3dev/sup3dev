## 🎮 I shipped a first-person shooter with no engine

**[DETACHED HEAD](https://github.com/sup3dev/detached-head)** — you fall asleep
at your desk and wake up inside a repository. The whole game is
**7 344 markdown files** hyperlinked into a stateless graph: one click = one
move, the links *are* the engine. Zero JavaScript. GitHub is the runtime.

- 🔫 aimed shots only — put the crosshair on the bug (they regenerate; it's a legacy codebase)
- 🔑 slay **THE OLDEST BUG** (3 hits), take the key, open the gate
- 💀 end **THE DEBT** — the thing growing in prod since 2009 (4 hits, and it doesn't stay down if you run)
- 🏁 speedrun it: open an issue `/run FFRRFX...` and a GitHub Action replays your route over `graph.json` — [leaderboard](https://github.com/sup3dev/detached-head/blob/main/LEADERBOARD.md)

Every frame is raycast-rendered by a numpy Wolfenstein-style engine and all
textures, sprites and the HUD are generated by code — zero external assets,
fully rebuildable with `python build.py` in two minutes.
